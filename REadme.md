ALGORITHM MINI PROJECTS
=======================

This package contains four independent Python projects.
Open each project folder and run its main.py.

Projects:
1. 01_Insertion_Sort_Analysis
2. 02_Sorting_Benchmark_Lab
3. 03_Task_Scheduler
4. 04_Maze_Solver_BFS_DFS

Install Matplotlib for the first two projects:
    pip install matplotlib

Run a project:
    python main.py

Each folder contains its own README.md.
Upload each folder as a separate GitHub repository so each project has its own link.
